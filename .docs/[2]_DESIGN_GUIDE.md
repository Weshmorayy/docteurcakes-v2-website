# Guide Design — Pâtisserie Docteur Cakes v2

## 1. Direction Visuelle

**Prestige Noir, Blanc & Or — Expérience Visuelle Immédiate.**
L'accent est mis sur les réalisations réelles dès l'entrée sur le site, avec une alternance stricte des fonds (Noir / Blanc / Noir) et des micro-interactions de dorure et de parallaxe subtile.

## 2. Palette Hexadécimale

- `--color-bg-dark` : `#0D0B09` (Noir sombre chaleureux d'atelier)
- `--color-bg-light` : `#FFFFFF` (Blanc pur studio pour fiches gâteaux)
- `--color-bg-ivory` : `#FDFBF7` (Ivoire doux)
- `--color-gold-main` : `#D4AF37` / `#C99700` (Or issu du logo)
- `--color-text-light` : `#FDFBF7`
- `--color-text-dark` : `#1A1713`

## 3. Typographie

- **Titres H1 / H2** : *Playfair Display* (Serif d'exception, élégant, lettres dorées)
- **Corps de texte & Labels** : *Inter* (Sans-serif lisible, optimisé écrans mobiles)
